Movie Comparisons

About the Project

Movie Comparisons is a website that lets you explore how people and critics rate movies. You can enter your favorite movie and a genre to see how its ratings compare to other movies in that genre.

I made this project to learn more about working with data, analyzing movie ratings, and creating graphs with Python.

What It Does

Favorite Movie: Enter a movie title to see its release year, genre, critic rating, and audience rating.

Genre Statistics: Enter a genre to see how many movies belong to it.

Rating Comparisons: See the minimum, maximum, average, and median audience ratings for movies in that genre.

Compare Your Movie: Check how your favorite movie's audience rating compares to the other movies in its genre.

Rating Histogram: View a graph showing how audience ratings are distributed and which rating range has the most movies.

Critic vs. Audience Ratings: View a scatter plot comparing critic ratings and audience ratings to see how closely they relate.

Technologies Used

Python

Pandas for organizing and analyzing movie data

Matplotlib for creating graphs

HTML for the website

Vercel for hosting the website

Dataset

The program uses rotten_tomatoes_movies.csv, which contains movie information and ratings. This file needs to be included in the project for the program to work.

How to Use It

Open the Movie Comparisons website.

Enter the title of a movie.

Enter a genre, such as Comedy, Drama, or Action.

Submit your answers to see the movie information, statistics, and graphs.
